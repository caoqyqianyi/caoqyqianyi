### 🔗 WEFE‑Nexus Multi‑scale Analysis *(Master Thesis & TRANS‑SAHARA Horizon‑Europe project)*
[![WEFE‑Nexus Screenshot][wefe_img]][wefe_repo]

This repository hosts reproducible workflows for analysing **Water‑Energy‑Food‑Ecosystem (WEFE) Nexus interdependencies across spatial scales**.
- Python & SQL workflows integrating heterogeneous environmental‑socioeconomic datasets
- Construction of spatial resilience indicators on regular grid systems
- Multi‑source dataset harmonisation, quality‑check and documentation
- Output includes static & interactive visualisations for interdisciplinary policy‑relevant reporting

`Tech stack`: Python, SQL / PostgreSQL‑PostGIS, Google Earth Engine, QGIS, Power BI

Code repository for urban environmental analysis using long‑term IoT sensor time‑series for Kiel‑Region smart‑city project.
- Processed multi‑variate urban micro‑climate sensor time‑series spanning up to one‑year observations
- Extracted spatial‑temporal environmental patterns from high‑frequency sensor records
- Built interactive web‑mapping visualisation with Mapbox‑GL JS / HTML/CSS for non‑expert stakeholders

`Tech stack`: Python, JavaScript, Mapbox GL JS, HTML/CSS, time‑series analysis
